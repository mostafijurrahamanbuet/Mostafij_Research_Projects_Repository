
# LAMMPS Simulation Scripts

This folder contains LAMMPS input scripts used to investigate thermal transport in PDMS-based nanocomposites containing two-dimensional fillers.

## Simulation Workflow

1. **Energy Minimization:** Conjugate-gradient minimization of the initial molecular structure.
2. **NPT Equilibration:** Temperature- and pressure-controlled equilibration of the composite.
3. **NEMD Simulation:** Calculation of effective thermal conductivity using the non-equilibrium molecular dynamics method.

The simulation inputs are organized according to their role in the computational workflow.
