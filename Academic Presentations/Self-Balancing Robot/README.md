
# Comparative Analysis and Performance Evaluation of a Two-Wheeled Self-Balancing Robot

**Academic Presentation | Control Engineering | Mechanical Engineering, BUET**

**Presentation Topics:** Dynamic Modeling | P, PI, and PID Controllers | Metaheuristic Optimization | MATLAB

---

## Presentation Overview

This presentation investigates the mathematical modeling and control performance of a two-wheeled self-balancing robot, modeled as an inverted pendulum.

A comparative analysis of P, PI, and PID controllers was conducted using different tuning approaches, including Genetic Algorithm (GA), Clonal Selection Algorithm (CSA), Ziegler–Nichols tuning, and MATLAB Auto-Tuner.

Controller performance was evaluated based on rise time, settling time, overshoot, and undershoot to assess system stability and dynamic response.
