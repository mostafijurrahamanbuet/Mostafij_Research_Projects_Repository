
# Python-Based Phonon Density of States (PDOS) Analysis

**Research Area:** Nanoscale Thermal Transport | Phonon Dynamics | Two-Dimensional Heterostructures

**Programming Language:** Python

**Simulation Software:** LAMMPS

**Analysis Method:** Fast Fourier Transform (FFT)-Based Atomic Velocity Spectrum Analysis

---

## Overview

This directory contains Python code used for the phonon density of states (PDOS) analysis of hexagonal boron nitride (h-BN)/black phosphorene (BP) heterobilayers.

The analysis processes atomic velocity trajectories obtained from molecular dynamics simulations in LAMMPS.

Layer-resolved PDOS is evaluated separately for the h-BN and BP layers to investigate their vibrational characteristics under different vacancy configurations.

---

## Python Analysis Script

**[View PDOS Analysis Python Code →](pdos_analysis.py)**

The script implements an FFT-based approach for processing atomic velocity trajectories and calculating vibrational power spectra.

### Key Functionalities

- Reading atomic velocity data generated by LAMMPS.
- Extracting velocity components along the x, y, and z directions.
- Separating atomic velocity data for the h-BN and BP layers.
- Dividing velocity trajectories into overlapping segments.
- Applying Hann windowing to reduce spectral leakage.
- Computing Fourier transforms of atomic velocity components.
- Averaging spectral contributions over atoms and trajectory segments.
- Preparing processed spectral data for subsequent analysis.

---

## Computational Analysis Workflow

### 1. Atomic Velocity Extraction

Atomic velocity trajectories are obtained from LAMMPS molecular dynamics simulations.

The trajectories contain velocity components of individual atoms recorded at specified sampling intervals.

### 2. Layer-Resolved Data Processing

Atomic velocity data are separated according to the h-BN and BP layers.

This enables individual examination of vibrational characteristics within each layer.

### 3. Spectral Processing

The sampled velocity trajectories are divided into overlapping segments.

A Hann window is applied to individual segments before performing the fast Fourier transform.

### 4. PDOS Calculation

The spectral contributions of the Cartesian velocity components are combined to obtain the total velocity-based PDOS.

```math
D_{\mathrm{total}}(f) = D_x(f) + D_y(f) + D_z(f)
```

where:

- `D_x(f)` represents the x-direction spectral contribution.
- `D_y(f)` represents the y-direction spectral contribution.
- `D_z(f)` represents the z-direction spectral contribution.

### 5. Spectral Data Processing

The processed spectra can be used for layer-resolved PDOS comparisons and subsequent spectral-overlap calculations.

## Research Application

The script supports vibrational analysis of pristine and vacancy-engineered h-BN/BP heterobilayers.

The investigated configurations include isolated boron vacancies (DB1) and clustered vacancies (DB3 and DB5).

The research considers vibrational characteristics along with directional thermal transport evaluated using RNEMD simulations.
