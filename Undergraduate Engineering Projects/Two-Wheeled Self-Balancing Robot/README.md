
# Comparative Analysis and Performance Evaluation of a Two-Wheeled Self-Balancing Robot using P,PI,PID controller and metaheuristic algorithm

**Undergraduate Engineering Project | Control Engineering | Mechanical Engineering, BUET**

**Project Areas:** Dynamic Modeling | PID Control | Metaheuristic Optimization | MATLAB

---

## Project Overview

This project investigates the dynamic stability and control performance of a two-wheeled self-balancing robot through mathematical modeling and MATLAB-based simulation.

The robot was modeled as an inverted pendulum using Euler–Lagrange equations, followed by linearization and state-space analysis.

A comparative evaluation of **P, PI, and PID controllers** was conducted using **Genetic Algorithm (GA), Clonal Selection Algorithm (CSA), Ziegler–Nichols tuning, and MATLAB Auto-Tuner**.

The controller performance was evaluated using rise time, settling time, overshoot, and undershoot to assess stability and dynamic response.

The study demonstrated the effectiveness of metaheuristic-based controller tuning for improving the dynamic performance of self-balancing systems.
